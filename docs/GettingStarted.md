## 0. これは何か

DirectX12で書かれた自作ゲームエンジンです。「ヒエラルキー」「インスペクター」「ギズモ」といったUnity風のエディタパネルが実行画面に内蔵されており、コードを書かなくてもオブジェクトの配置やコンポーネントの付け外しがGUIから行えます。

- **GameObject**：シーンに配置される「モノ」。位置・回転・拡大縮小（Transform）だけを最初から持つ空の器で、見た目や振る舞いは持たない。
- **Component**：GameObjectに後から付け足す「機能」。描画・ライト・当たり判定・音などはすべてコンポーネントとして付与する。

この2つの関係が本ガイドの中心です。「空のGameObjectを置いて、そこに必要なコンポーネントを付ける」という操作の繰り返しでシーンを組み立てます。

## 1. ビルドして起動する

1. `ClearRootEngine.slnx` をVisual Studio 2026で開く。
2. ソリューション構成を `Debug` または `Release`、プラットフォームを `x64` に設定する。
3. `F5`（デバッグ実行）または `Ctrl+F5`（デバッグなし実行）でビルド＆起動する。

起動すると、3D描画ウィンドウに重なる形で「ヒエラルキー」「インスペクター」「ギズモ」「プロジェクト」といったパネルが表示されます。

---

## 2. エディタ画面の見方

4つの主要パネルで構成されています。見た目・役割ともにUnity Editorに近い設計です。

| パネル | 役割 |
|---|---|
| **ヒエラルキー** | シーン内の全オブジェクトを親子ツリーで一覧表示。クリックで選択、右クリックで新規作成、ドラッグ&ドロップで並べ替え・親子付け替え。 |
| **インスペクター** | 選択中オブジェクトの名前・Transform・保持コンポーネントを表示/編集。「+ コンポーネントを追加」ボタンもここにある。 |
| **ギズモ** | 再生/停止の切り替えと、選択中オブジェクトを3D空間上で直接動かす移動・回転・拡縮ハンドルの表示。 |
| **プロジェクト** | 読み込み済みのモデル・テクスチャなどアセット一覧。ヒエラルキーへドラッグ&ドロップして配置できる。 |

## 3. オブジェクトを置く

ヒエラルキーパネルから新規オブジェクトを作成します。2通りの方法があります。

### 方法A：空のオブジェクトから組み立てる

1. ヒエラルキーの **「+ 新規追加」** ボタンを押す。位置(0,0,0)・回転なし・スケール1の空のGameObjectが1つ生成される。
2. 生成されたオブジェクトをクリックして選択する。
3. インスペクターに切り替わるので、次章の手順でコンポーネントを追加していく。

### 方法B：完成済みのひな形（アーキタイプ）から置く

ヒエラルキーの何もない場所を **右クリック** すると、「空のオブジェクト」に加えて Cube・Sphere・光源・カメラなどあらかじめコンポーネント構成済みのひな形一覧が出ます。選ぶだけで、そのオブジェクト用に必要なコンポーネントが一式付いた状態で生成されます。初めて何かを置くときはこちらが手早いです。

---

## 4. コンポーネントを付ける

オブジェクトを選択した状態でインスペクターから行います。

1. ヒエラルキーで対象オブジェクトを選択する。
2. インスペクター下部の **「+ コンポーネントを追加」** ボタンを押す。
3. 開いたポップアップから「形状」「物理」「ライティング」「カメラ」「描画」「オーディオ」などカテゴリ別の一覧が出る。目的のコンポーネント名をクリックする。
4. モデル描画・オーディオなど設定項目が要るものはツリーを開くと入力欄が出るので、値を入れてから「追加」ボタンを押す。

付けたコンポーネントはインスペクターに見出し付きで並び、各項目をその場で編集できます。不要になったら見出しを **右クリック→「コンポーネントを削除」** で外せます。

---

## 5. コンポーネント一覧

よく使う主なコンポーネントです。「+ コンポーネントを追加」ポップアップのカテゴリに対応しています。各メンバの詳細は [Components.md](Components.md) を参照してください。

| カテゴリ | コンポーネント | 役割 |
|---|---|---|
| 描画 | `CubeRender` / `SphereRender` | 基本形状を描画する。 |
| 描画 | `ModelRender` | 指定フォルダ・ファイル名の3Dモデル（アニメーション対応）を描画する。 |
| 描画 | `SpriteRender` | 2D/3D空間に画像1枚を描画する。 |
| 描画 | `TextRender` | 固定テキストまたはHUD（座標表示など動的な文字列）を描画する。 |
| ライティング | `DirectionalLight` | 太陽光のような平行光源。 |
| ライティング | `PointLight` | 電球のような全方位の点光源。 |
| ライティング | `SpotLight` | 懐中電灯のような円錐状のスポット光源。 |
| 物理/当たり判定 | `OBBCollider` / `SphereCollider` | 直方体/球形の当たり判定を持たせる。 |
| 物理/当たり判定 | `Gravity` | 毎フレーム重力に従って落下させる。 |
| 物理/当たり判定 | `Health` | HPを持たせ、被弾処理を行えるようにする。 |
| 物理/当たり判定 | `PlayerController` | キー/パッド入力で動かせるようにする。 |
| カメラ | `Camera` | そのオブジェクトの位置・向きを描画カメラとして使う。 |
| カメラ | `CameraFollow` | 指定した対象を追従するカメラにする。 |
| オーディオ | `AudioSource` | BGM/SEファイルを指定して再生する。 |
| その他 | `TextureSelector` / `Mirror` | 描画コンポーネントに貼るテクスチャの選択／鏡面反射化（Cube Render必須）。 |

## 6. 移動・回転・拡大

Transformの編集は2通りの方法があります。

- **インスペクターで数値入力**：選択中オブジェクトのインスペクター最上部にある位置(Translation)・回転(Rotation)・拡縮(Scale)の数値を直接ドラッグ/入力する。
- **ギズモで直接操作**：3D画面上に表示される矢印/リング/箱のハンドルをドラッグして、見たまま直感的に動かす。ギズモパネルで移動・回転・拡縮モードを切り替える。

---

## 7. 親子関係

ヒエラルキー上でオブジェクトを別のオブジェクトへドラッグ&ドロップすると、その子になります。

- 子のTransformは親からの **相対位置** として扱われる。
- ドロップ位置（ノードの上/隙間）によって「子にする」か「兄弟として並び替える」かが変わる。
- 何もない場所にドロップするとルート（親なし）に戻る。

---

## 8. 保存とシーン

エディタ上部の再生/停止ボタンでゲームロジック（重力や当たり判定の更新など）の動作を止めて配置作業に集中できます。編集内容はシーンJSONとして保存できます（インスペクター付近の保存メニューから名前を付けて保存/上書き保存）。

---

## 9. コードから追加する場合

GUIを介さず、コードで直接オブジェクトを組み立てることもできます。仕組みを理解する上での最小例です。

```cpp
// 1. 空のGameObjectを作る（TransformComponentは自動で付く）
GameObject& obj = CreateObject("MyCube");

// 2. 必要なコンポーネントを付ける
auto* render = obj.AddComponent<CubeRenderComponent>();
auto* light  = obj.AddComponent<DirectionalLightComponent>();

// 3. 付けたコンポーネントを後から取得して使う
if (auto* health = obj.GetComponent<HealthComponent>()) {
    health->TakeDamage(10);
}
```

## 10. 用語集

| 用語 | 意味 |
|---|---|
| `GameObject` | シーンに置かれる個々の「モノ」。名前・タグ・Transform・親子関係・コンポーネント群を持つ器。 |
| `Component` | GameObjectに付ける個々の機能単位（描画・光・当たり判定など）。 |
| `Transform` | 位置・回転・拡大縮小の3情報。全GameObjectが必ず持つ。 |
| アーキタイプ | 「Cube一式」のようにコンポーネント構成をまとめた既製のひな形。ヒエラルキー右クリックから使う。 |
| ギズモ | 3D画面上でオブジェクトを直接ドラッグ操作するためのハンドルUI。 |
